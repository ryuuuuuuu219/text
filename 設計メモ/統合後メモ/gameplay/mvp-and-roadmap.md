# MVPと開発順序

## MVPの目的

物語生成より先に、**パイロット差によって同じ戦闘が異なる物語に見えるか**を検証する。

## MVP仕様

| 項目 | 仕様 |
|---|---|
| 空母 | 一隻、自動航行と耐久のみ |
| 味方 | パイロット三人、機種一種 |
| 敵 | 一般機編隊と敵エース一人 |
| 任務 | 迎撃、護衛 |
| 戦術 | 慎重、標準、積極 |
| パイロット値 | 名声、性格、正G耐性、負G耐性 |
| 戦闘 | 簡易目標選択、離脱、撃墜を自動処理 |
| 観戦 | 俯瞰カメラ、機体選択、通信表示 |
| 回収 | 脱出後、制限時間内に回収 |
| 会話 | 固定テンプレート。AI生成は後段階 |
| 敵エース | 放置すると空母を攻撃し、高名声機に誘引される |

## 評価項目

- 高名声者を出す利益と危険が両立するか。
- 敵エースを誰に担当させるかが重要か。
- 回収のため戦闘を中断する価値があるか。
- 性格と戦術方針の差が観戦だけで読めるか。
- 固定会話でも人物差と因縁を感じられるか。

## 開発順序

1. 自動発艦、移動、交戦、撃墜、帰還。
2. 任務割当、戦術方針、名声ヘイト、敵エース。
3. 脱出、救難、回収、負傷、回復。
4. 俯瞰観戦、会話テンプレート、通信ログ。
5. 好感度、性格差、因縁、戦闘後イベント。
6. シード生成とAI文章生成。
7. 偵察、情報制限、空母移動、複数任務。

## 中核定義

名声は能力値、敵ヘイト、決闘、会話、空母防衛をつなぐ。敵エースとの決闘は演出ではなく、空母への攻撃を遅らせる防衛機構である。
