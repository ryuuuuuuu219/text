# 企画概要と中核ループ

## 企画の一文定義

**艦載機育成 × 自動空戦 × 戦場会話ビジュアルノベル。**

その実現手段の中核が、**Codexによる動的シナリオ生成**である。固定シナリオを順番に再生するのではなく、戦況、人物、関係、介入、戦果を構造化データとして確定し、その結果に沿う作戦文と会話を生成する。

プレイヤーは空母と艦載航空隊の指揮官となり、直接戦闘機を操縦せず、誰を出撃させるか、何を命じるか、どこまで危険を許容するか、誰を救うかを判断する。

## ジャンルと役割

| 項目 | 内容 |
|---|---|
| ジャンル | 空母運営型タワーディフェンス／自動空戦／育成／ビジュアルノベル |
| プレイヤー | 空母および艦載航空隊の指揮官 |
| 主操作 | 編成、任務割当、戦術指定、空母移動、観戦対象選択、回収判断 |
| 主な楽しさ | 成長、敵エースとの因縁、戦場会話、戦況判断、生還管理 |
| 戦闘形式 | 視界内戦闘を基本とする自動空戦 |
| Codex／生成AI | 作戦候補、ブリーフィング、状況依存会話、戦後記録の動的生成。結果の捏造はしない |

## 中心価値

- 名声・性格・好感度・能力が、性能だけでなく会話と敵の目標選択へ反映される。
- 敵エースとの決闘が、演出と空母防衛の両方へ直結する。
- 撃墜を即時消失にせず、脱出、救難、負傷、捕虜、行方不明、再会へつなげる。
- 同じ作戦シードでも、出撃者と戦況によって異なる会話・因縁が生まれる。
- 不完全な情報の中で、偵察、迎撃、救難、温存の優先順位を選ばせる。

## 基本ゲームループ

1. シードから海域、天候、時刻、目的、敵編成、特殊条件を決定する。
2. 確認済み情報だけを含むブリーフィングを提示する。
3. 出撃パイロット、任務、戦術方針、撤退条件を指定する。
4. 艦載機が自動発艦し、偵察、護衛、迎撃、攻撃、決闘を行う。
5. プレイヤーは俯瞰カメラと通信ログで戦況を把握し、必要な指示を出す。
6. 損傷機と救難信号に対し、救難機、護衛、空母接近、見送りを判断する。
7. 帰還後、戦果、名声、好感度、負傷、疲労、関係性を更新する。
8. 確定した出来事を基に戦闘後会話と次作戦へ続く因縁を生成する。

## 資源と改修

鉱物資源を資金として扱い、艦載機・武装の改修へ使用する。海水には豊富な鉱物・金属成分が含まれ、その分離・濃縮・精製技術が金属産業と合金開発を支えている。定期的な海水中鉱物の採集は背景処理とし、資源採掘ミッションは襲撃の有無を判定する短いイベントとして生成する。修理と燃料補充はゲーム外で完了している前提とする。

## 世界設定との接続

技術水準は複葉機からジェット機、短距離ミサイルまでが併存する。海水由来の金属資源と抽出・精製技術が、高性能合金、二重反転プロペラ機、ジェット超音速機の急速な発達を支えた。磁気擾乱により遠距離識別・追尾は不安定で、航空騎士道と国際法も視界外攻撃を制限している。

初期企画書の「B国による突然の宣戦布告」は旧案である。現在の正本候補は、ゼア過激派の武装査察から始まる[Z包囲戦争](../world/current-war/belligerents.md)とする。
