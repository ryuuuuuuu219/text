# 空母・艦載機・任務

## 空母

空母はプレイヤーの本体であり、艦載機の発着、補給、修理、救難、航空管制、作戦範囲の基準点を担う。直接操艦は必須とせず、自動航行を基本に、進路・接近・退避の判断だけをプレイヤーへ委ねる案がある。

| 操作・機能 | ゲーム上の意味 |
|---|---|
| 発艦管理 | 誰をいつ出撃させるかを決める |
| 帰還受入 | 損傷機を着艦させ、修理・回復へ移す |
| 空母移動 | 航続範囲、回収距離、敵攻撃隊との距離を調整する |
| 救難支援 | 救難機派遣または空母接近で回収可能性を上げる |
| 設備損傷 | 飛行甲板、修理、発着、管制能力が低下する |

敗北条件候補は、空母耐久力ゼロ、飛行甲板の完全使用不能、制限時間切れ、必須護衛対象または重要人物の喪失である。

## 任務割当

| 任務 | 概要 | 主な危険 |
|---|---|---|
| 哨戒 | 指定空域を周回して早期発見する | 燃料消費、孤立 |
| 偵察 | 未確認空域へ入り敵編成・進路を確認する | 発見時の集中攻撃 |
| 迎撃 | 空母・味方編隊へ接近する敵を阻止する | 数的不利 |
| 護衛 | 攻撃機、救難機、輸送機などを守る | 任務拘束、敵の誘引 |
| 制空 | 指定空域から敵戦闘機を排除する | 長時間戦闘 |
| 対地・対艦 | 識別済み目標を攻撃する | 護衛不足、対空火力 |
| 救援 | 交戦中の味方または救難信号へ急行する | 待ち伏せ |
| 敵エース対応 | 決闘または足止めを行う | 撃墜・負傷リスク大 |

## 戦術方針

| 方針 | 行動傾向 |
|---|---|
| 慎重 | 不利、損傷、疲労時に早めに離脱 |
| 標準 | 任務達成と生存を均等に優先 |
| 積極 | 交戦を継続し、戦果と被害が増えやすい |
| 護衛優先 | 自身の戦果より護衛対象への接近阻止を優先 |
| 決闘優先 | 高名声の敵・敵エースを優先 |
| 生還優先 | 負傷、G限界、機体損傷で即離脱 |

拡張候補として、決闘拒否、高名声味方の護衛、自身への誘引、空母接近敵の優先、新人への戦果譲渡、不利な決闘からの離脱を設定する。

行動判断では、作戦命令、通常戦闘規定、空戦規定をこの順で優先し、その許可範囲内で性格、好感度、騎士道法遵守率、戦況を補正する。好戦的・名誉欲の強い人物が撤退命令中に挑戦を受ければ、それは騎士道的選択ではなく明確な命令違反として扱う。

## 機体

| 値 | 定義 |
|---|---|
| 速度 | 水平飛行時の最高速度 |
| 旋回時間 | 基準速度から所定角度を旋回する時間 |
| 耐久力 | 被弾・故障に耐える量 |
| 加速力／減速力 | 戦闘速度への復帰、急減速、オーバーシュート誘発 |
| 上昇性能 | 高度獲得速度 |
| G限界 | 機体構造上の許容G |
| 兵装威力・弾薬 | 火力と継続交戦時間 |
| 航続時間 | 哨戒、偵察、救難範囲 |

実際に使える旋回性能は機体値だけでなく、パイロットの正負耐G性、疲労、負傷、意識状態に制限される。
