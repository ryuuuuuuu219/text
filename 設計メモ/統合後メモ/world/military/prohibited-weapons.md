# 禁制兵器

## 禁制の原則

禁制の中心は威力の大小ではなく、戦闘から「敵の認識」「人間の判断」「危険の共有」「降伏の機会」「責任の所在」を取り除くかどうかにある。国連は古い騎士道的慣習を国際法へ組み込み、長距離自律誘導兵器や無差別兵器を規制している。

## 兵器別の扱い

| 区分 | 扱い | 主な条件・理由 |
|---|---|---|
| 機銃・機関砲・無誘導ロケット | 許容 | 目視戦闘を前提とする |
| 爆弾 | 許容 | 操縦者が目標を確認して投下する通常の対地兵器。民間施設への無差別爆撃など、使用方法は別途規制される |
| 対空爆弾 | 許容・一部で歓迎 | 投下位置、時機、敵機の進路予測に高い技量を要する。一部のエースは象徴的な得意兵器として常用する |
| VT信管 | 条件付き許容 | 射手が目標を確認する。救難機・民間機がいる空域では制限 |
| MACLOS手動誘導 | 許容 | 射手が目標と弾体を見て着弾まで操作する |
| レーザー誘導・レーダー指令誘導 | 条件付き許容 | 人間が目標を確認し、着弾まで関与する |
| 近距離IR誘導 | 歓迎・許容 | 目視距離内での機動、射点への入り方、発射時機に操縦者の技量が表れるため、エース文化と両立する |
| 近距離SARH | 歓迎・許容 | 命中まで照射を維持する技量と危険負担が評価される。天然磁気の影響で実用射程は短く、IRとの選択は操縦者の好みに近い |
| 中距離IR誘導 | 禁制・厳格制限 | 民間航空機連続襲撃事件で、視認、発射者特定、攻撃中断、軍民識別の欠如が社会問題化した |
| 有線自爆信号式中距離IR誘導 | 辛うじて許容 | 発射母機から極細ケーブルで作動許可信号を送り、切断・送信停止時に自爆する。継続関与を物理的に保証するが、母機の機動と射程を制限する |
| 完全な撃ち放し式ARH／複合誘導 | 禁制・厳格制限 | 発射後の攻撃中断と責任主体を保証できない |
| ICBM／GLBM・GFLBM／SLBM／MIRV | 禁制 | 視認、応答、降伏、停止、責任、戦闘員識別を損ない、生物・化学兵器搭載の疑念も招く |
| 自律攻撃UAV | 禁忌級・禁制 | 通信なしで探索・選定・追跡・攻撃し、降伏や責任主体を必要としない |
| 徘徊型自爆無人機 | 禁制 | 空域を探索・待機し自律的攻撃へ移れる |
| 大量破壊兵器 | 否定・国際管理 | 無差別性、長期汚染、戦後被害、責任範囲の不明確さ |

## 空対空ミサイルの受容史

ゼアの鎖国終了後、核爆撃機の脅威が現れなかったため、現実世界のような高速・長射程ミサイルの需要は弱かった。先に発達したのは近距離・高機動型であり、初期のIR誘導と短射程SARHは操縦者の技量が結果を左右する兵器として歓迎された。強い天然磁気のためSARHは近距離でしか安定せず、IRとSARHの選択は主に操縦者の好みだった。

中距離IRは当初、主にエースから騎士道上の理由で忌避された。状況を決定的に変えたのは、カルト宗教団体が軍の保管施設から多数の弾体を奪い、民間航空機を連続攻撃した事件である。攻撃者は接近も継続誘導も必要とせず、発射地点の特定、攻撃中断、意図した目標の確認、軍民識別が困難だった。以後、中距離以上の自律誘導兵器には、所有者・保管施設の登録、弾体識別番号、発射権限管理、攻撃中断機能、発射者の特定可能性、民間航空路周辺への配備禁止が要求される。

事件後、ゼアはミサイルと発射母機を極細の信号ケーブルで接続する有線自爆信号式中距離IRミサイルを開発した。弾体はIRで追尾するが、母機から有線で作動許可信号を受け続け、ケーブル切断または送信停止時に自爆する。電波妨害を受けにくく責任を発射者へ残せる一方、ケーブル長が射程限界となり、母機の機動と複数発運用を妨げる。国際社会には辛うじて許容されたが、エースからは自由な空戦機動と接近戦を損なう兵器として嫌われた。

## 爆弾と対空爆弾

通常爆弾は、操縦者が目標を確認して投下する限り、一般的な対地兵器として許容される。ただし、民間区域への無差別爆撃や、戦闘員と非戦闘員を区別できない運用まで認められるわけではない。

対空爆弾は、敵機の進路を読み、適切な位置と時機で投下する特殊兵器である。扱いが難しく操縦者の技量が明確に表れるため、一部のエースに歓迎され、その人物を象徴する得意兵器にもなっている。

## 長距離弾道ミサイル

ゼアが高出力通信、慣性誘導、地磁気補正、予測演算、複数誘導方式、高度なECCM、限定的自律追尾を組み合わせて開発した。国連により禁制兵器へ指定されたが、技術が完全に放棄されたとは信じられていない。

ICBM、GLBM、SLBM、MIRVは、搭載物が通常弾頭でも大量破壊兵器運搬手段と見なされる。ゼア包囲戦争中盤には、複数のジオフロントから包囲網参加国の版図へ複合弾頭GFLBMが発射される。これは地上施設、交通、人員、駐機機、離陸機、飛行中の航空機を一つの攻撃領域として大量破壊する、国際社会とエース文化への復讐兵器である。ゼア過激派はSLBMを使用しない。

## UAVの自律性

- 非武装観測・通信中継・救難UAVは概ね許容される。
- 遠隔操作式武装UAVは、人間による目標確認、発射判断、管制責任者の名乗りを条件に議論される。
- 半自律UAVは、人間が最終発射命令を出す限り容認する案がある。
- 自律攻撃UAVは、通信途絶後も目標選択と攻撃を続けるため禁忌級とされる。

### 国連UAV等級案

| 種別 | 用途・能力 | 扱い |
|---|---|---|
| 第一種 | 気象・磁気観測、通信中継、輸送、救難、測量 | 原則許容 |
| 第二種 | 偵察、哨戒、ECM、囮、射撃観測、戦果確認 | 登録・識別を条件に許容 |
| 第三種 | 人間が常時監視・発射承認する遠隔武装機 | 厳格な条件付き許容 |
| 第四種 | 自動追跡・回避・攻撃候補選定、人間が最終承認 | 原則制限、防空・試験のみ例外 |
| 第五種 | 自ら探索・選定し、人間承認なしで攻撃 | 禁制 |
| 第六種 | 空域を探索・待機する徘徊型自爆機 | 中長距離ミサイルに準じ禁止・厳格制限 |

### 識別と責任

軍用UAVは所有国、部隊、機体番号、管制主体、責任指揮官、自律等級、通信喪失時行動を登録する。遠隔武装機には管制者または作戦責任者の名乗りを求める案がある。

救難UAVは国連登録、専用IFF、武装禁止、観測装置制限、飛行記録公開、回収物申告を条件に保護される。救難機偽装は制度全体を崩す重大違反である。

### 管制奪取

通信遮断は合法、無害な待機・帰還命令は条件付き合法とする案がある。攻撃命令の偽造、奪取機による元所有国攻撃、救難UAVの奪取は禁止する。

### 長距離ミサイルとの差

長距離ミサイルは主に指定目標へ一度だけ向かう。自律攻撃UAVは生存する限り戦場を探索し、複数目標を選び直し、帰還・再使用できる。このため「命令だけを与えられた無人の兵士」とされ、より根本的な禁忌になり得る。

## その他の禁止・制限

- 救難、降伏、休戦交渉、医療、国連共通通信への妨害は重大な禁忌。
- 大量チャフ散布は味方、救難、民間航空も妨害するため制限される。
- 核兵器は未製造。濃縮施設、反応設備、核物質輸送は国際管理下にある。
- 大規模化学兵器・生物兵器・都市無差別破壊兵器は否定されている。
- 反物質兵器は技術的に成立していない。
