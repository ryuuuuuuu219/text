# Z包囲戦争後の世界

## 全体の流れ

戦後世界は、戦時情報の秘匿、焦土作戦・GFLBM事件の部分的暴露、戦争の神話化、航空騎士道の民間文化化、GFLBM解析と戦略兵器拡散、核兵器の実用化と相互確証破壊、軍事上の決闘慣習の縮小という順に変化する。

航空騎士道は消滅するのではなく、軍事制度から民間競技と仮想戦争へ移る。一方、磁気・電波擾乱下で状況を判断する操縦者の価値は残り、エースは英雄的決闘者から電子戦環境の現場指揮官へ変わる。

## 戦時情報の秘匿

終戦直後、ゼアとレイは異なる理由から、焦土作戦とGFLBM攻撃に関する情報へ一時的な緘口令を敷く。

ゼア側は国家責任の限定、戦時政府の正統性、ジオフロント技術、国内技術者層を守ろうとする。レイ側は自国の対応失敗、焦土作戦への関与、GFLBMの被害規模と迎撃能力を隠し、戦後秩序の動揺を抑えようとする。

しかし、被害地域の航空写真、元兵士・技術者の証言、戦後裁判、遺族調査、回収されたGFLBM残骸、高高度・衛星観測、機密解除資料、内部告発、都市伝説を通じ、真相は断片的に流出する。

## 公開の段階

1. ゼア側の一部部隊が命令を無視したらしい、と報じられる。
2. 一部の学園都市が意図的に破壊された可能性が公になる。
3. 地下拠点から複数地域へ弾道攻撃が行われたと判明する。
4. 焦土作戦とGFLBM攻撃が、同じ技術者派閥の思想から生まれた可能性が議論される。

| 事実 | 一般社会での扱い |
|---|---|
| 一部学園都市の壊滅 | 公知 |
| 壊滅が敵の攻撃によるものか | 論争 |
| ゼア内部の焦土命令 | 後年に判明 |
| GFLBMの発射 | 公知または強く推定 |
| 複合弾頭の完全な構造 | 軍事機密 |
| 技術者過激派による独断発射 | 政治的論争 |
| 政府が把握・承認していた範囲 | 未解決 |

## 戦争の神話化とフィクション

真相が断片化したことで、GFLBM攻撃を描く戦争映画、焦土化学園都市の怪談、技術者過激派を英雄視する作品、エースを最後の騎士として描く物語、政府陰謀論、生き残ったジオフロントを巡る冒険作品が生まれる。史実と創作の境界は長期間曖昧になる。

別世界である現実世界についても、当初は「航空騎士道が存在せず、爆撃機、核戦略、ステルス技術が発達した架空世界」としてフィクションに現れる。宇宙観測や理論物理から別世界仮説が提唱され、作者が創作だと思って受信した情報、観測、転移、通信などを通じて、その架空世界が実在する可能性が後に浮上する。この認知経路と事実化の時期は未確定とする。

## 航空騎士道の民間文化化

軍事現場では長距離攻撃、無人機との連携、任務優先が常態化し、名乗り、一対一、目視距離内攻撃、決着後の私的判断といった決闘慣習は適用範囲を失う。一方、脱出者、救難、降伏機、医療・民間標章の保護、無差別攻撃の制限、戦果と攻撃責任の記録は、通常戦闘規定と航空戦時人道法として残る。

民間では使用兵器、一対一、安全な脱落判定、機体性能を管理できるため、理想化された航空騎士道がむしろ最盛期を迎える。

- 模擬空戦競技、決闘形式の航空スポーツ
- 民間飛行クラブ、歴史機再現
- VR・シミュレーター空戦
- エース名鑑、機体標章、二つ名文化の復刻
- 空戦映画、実況配信、学園対抗模擬航空戦

## 「違った仮想戦争」

民間模擬戦はスポーツを越え、国家、企業、学園都市、ファン集団が参加する大規模な仮想戦争へ発展する。現実の地形を使った仮想領土戦、電子的撃墜判定による有人戦、有人機・UAV混成競技、Z包囲戦争の歴史再現、架空国家の長期キャンペーンが行われ、戦果と名声はシーズンを越えて保存される。

現実の戦争から決闘が消えたため、人々は決闘が成立する戦争を人工的に作る。この仮想戦争は、本編後の世界、次作品、ゲーム内ゲームの舞台候補になる。

## GFLBM解析と戦略兵器拡散

GFLBMは防空圏を越えて敵国中枢を攻撃できることを実証する。各国は回収残骸と戦闘記録から弾道ミサイル、再突入搬送体、分散発射、飽和攻撃を複製し、施設の地下化・分散化と報復戦力の保持を始める。

通常弾頭の段階では、相互都市機能破壊、相互航空戦力無力化、相互地下都市攻撃、相互指揮系統破壊、弾道兵器による報復保証が形成される。GFLBMは相互確証破壊そのものではなく、その運搬・分散・飽和技術の原型である。

## 核兵器と相互確証破壊

通常弾頭GFLBMは高価で、複合弾頭も製造・整備が難しい。各国は、より小さく高威力で地下ジオフロントを破壊できる弾頭を求め、以前から国際管理されていた核研究を軍事転用する。

GFLBMが核兵器を直接生んだのではない。核弾頭を搭載すれば弾道ミサイルが完成された戦略兵器になると、各国に理解させた。核実用化後は一発当たりの破壊力が飛躍し、相互確証破壊が成立する。核を使わず通常複合弾頭を選んだゼア過激派が、結果としてさらに破壊的な核戦略の拡散を招くことが戦後史の皮肉になる。

## 限定戦争と新しいエース

相互確証破壊は全面戦争を抑えるが、国境紛争、代理戦争、海上交通路争奪、偵察機排除、発射施設への限定攻撃、発射前迎撃、救難、護衛、UAV迎撃、電子戦機護衛、局地的航空優勢は残る。核兵器は「使えば終わる兵器」であり、日常的な軍事行動を代替しない。

天然磁気と電波擾乱も残り、レーダー誤差、データリンク断絶、IFF不確実性、UAV通信断、目標更新喪失、センサー矛盾、自動判断の失敗が続く。そのため、不完全な情報を読み、現場で判断し、直接操縦できる人間が必要になる。

| 旧時代のエース | 戦後のエース |
|---|---|
| 決闘と近距離空戦に強い | センサーの矛盾を見抜く |
| 名乗りを重視する | ECM下で敵味方を識別する |
| 個人戦果で評価される | 通信喪失後も任務を継続する |
| 一対一で勝敗を決める | 無人機編隊を統率する |
| 英雄的な騎士 | 長距離兵器を避けて接近し、自動照準が失敗した局面を補う現場指揮官 |

航空騎士道は戦場から民間社会へ移り、理想化される。エースは英雄的決闘者ではなくなるが、不確実な戦場を人間の判断でつなぎ、核戦争へ拡大しない範囲で勝利する存在として残る。
