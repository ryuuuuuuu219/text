# 禁制兵器

## 禁制の原則

兵器の合法・違法は、射程や誘導方式の名称ではなく、実際の機能と運用で決める。

攻撃には、結果を予測し、対象を選択し、中止できる人間を置かなければならない。その人間には十分な情報、判断時間、実効的な権限が必要であり、判断過程は後から再現できなければならない。名目上の承認者を置くだけでは足りない。

次のいずれかを含む兵器・運用は原則として禁制とする。

- 人間による直接識別前に攻撃を開始する。
- 具体的な対象を指定せず、空域や地域へ発射してから目標を探す。
- 指定目標を失った後、兵器が別の対象を再捜索・再選定する。
- 人間の承認なしに探索、選定、追跡、攻撃を完結する。
- 戦闘員、民間人、降伏者、救難者を実用上区別できない。
- 攻撃主体、命令経路、対象、結果を記録・追跡できない。
- 威力・範囲・残留効果により、対象を限定した使用ができない。

禁制の根拠は、責任を一人へ押し付けられないことではない。人間による有効な判断と、国家・組織による説明・調査・補償・是正の連鎖そのものが成立しないことにある。責任原則は[通常戦闘規定](../03_通常戦闘規定/通常戦闘規定.md)を参照する。

## 兵器・機能別の扱い

| 区分 | 扱い | 主な条件・理由 |
|---|---|---|
| 機銃・機関砲・無誘導ロケット | 許容 | 人間が具体的な対象を識別して射撃する。使用対象・範囲は別途規制する |
| 爆弾・対空爆弾 | 条件付き許容 | 人間が対象を確認し、民間区域への無差別攻撃を避ける |
| VT信管 | 条件付き許容 | 射手が対象を確認し、救難機・民間機を含む空域では使用を制限する |
| MACLOS・指令誘導 | 許容 | 人間が指定目標へ誘導し、判断と結果を記録する |
| レーザー・レーダー指令誘導 | 条件付き許容 | 人間が具体的な対象を指定し、必要な範囲で中止できる |
| IR・SARH・ARH誘導弾 | 条件付き許容 | 発射前に直接識別した一機だけを追尾し、目標喪失後に別目標を選ばない |
| 通常の撃ち放し誘導 | 条件付き許容 | 撃ち放し自体は禁制理由ではない。発射前の人間による識別・指定と、別目標へ移らない機能を求める |
| 視認前発射・LOAL | 禁制 | 発射時点で人間が攻撃対象を具体的に確定していない |
| 自動再捜索・再捕捉・再選定 | 禁制 | 指定した一機以外を兵器が攻撃し得る |
| 遠隔操作式武装UAV | 条件付き許容 | 操縦者が対象を直接識別し、攻撃を選択・中止でき、記録を残す |
| 自律攻撃UAV・徘徊型自律攻撃機 | 禁忌級・禁制 | 人間の承認なしに探索・選定・攻撃を進める |
| ICBM／GLBM・GFLBM／SLBM／MIRV | 禁制 | 広域・戦略攻撃を自動的に進め、対象限定・中止・降伏受理を実用上成立させない |
| 大量破壊兵器 | 禁制・国際管理 | 無差別性、長期汚染、戦後被害により対象を限定できない |

空対空誘導弾の具体的な発射条件は[空戦規定](../04_空戦規定/空戦規定.md)を正本とする。

## 空対空誘導弾規制の成立

ゼアの鎖国終了後も、核爆撃機の脅威が存在しなかったため、長距離迎撃兵器の需要は弱かった。先に発達した近距離・高機動型は、操縦者の技量が結果を左右する兵器としてエース文化に受容された。これは長射程兵器を禁ずる法的根拠ではなく、技術発達が遅れた歴史的理由である。

規制の転機は、カルト宗教団体による民間航空機連続襲撃事件だった。軍施設から奪われた誘導弾が、攻撃者から離れた航空機へ相次いで使用され、遠距離センサー上の反応だけで軍民を判定する危険、発射権限と弾体管理の欠陥、攻撃記録と補償制度の不足が明らかになった。

事件後、次の制度が整備された。

- 空対空攻撃は、権限を持つ人間が対象機を直接識別した後に限る。
- 視認前発射、LOAL、目標未指定発射、自動再捜索・再選定を禁ずる。
- 所有者、保管施設、弾体番号、発射権限、指定目標、攻撃結果を記録する。
- 民間航空路周辺の保管・配備・訓練を制限する。
- 事件時は発射者だけでなく、警備、指揮、調達、設計、国家の責任を調査する。

したがって、中距離IRという物理分類や撃ち放し方式そのものは禁止されない。発射前に人間が直接識別した一機だけを追尾し、別目標へ移らない通常の撃ち放しIRは許容される。

## 有線自爆信号式誘導弾

有線自爆信号式中距離IR誘導弾は、規制全体の標準解ではなく、機体「丙」に関連する固有の実験的構造である。

弾体はIRで指定目標を追尾し、発射母機から有線で作動許可信号を受け続ける。ケーブル切断または送信停止時には自爆する。電波妨害下でも作動中止を物理的に結び付けられる一方、母機の機動、射程、複数発運用を大きく制限する。

この構造は技術実証として条件付きで認められたが、すべての誘導弾に継続通信や発射後中止能力を要求する根拠にはしない。発射前識別と単一目標への拘束を満たす兵器は、有線でなくても合法になり得る。

## UAVの自律性

| 種別 | 用途・能力 | 扱い |
|---|---|---|
| 第一種 | 気象・磁気観測、通信中継、輸送、救難、測量 | 原則許容 |
| 第二種 | 偵察、哨戒、ECM、囮、射撃観測、戦果確認 | 登録・識別を条件に許容 |
| 第三種 | 人間が常時監視し、対象識別と発射判断を行う遠隔武装機 | 厳格な条件付き許容 |
| 第四種 | 自動追跡・回避・攻撃候補提示を行い、人間が最終選択する | 情報量、判断時間、中止権限を審査して制限付き許容 |
| 第五種 | 自ら探索・選定し、人間の承認なしに攻撃する | 禁制 |
| 第六種 | 空域を探索・待機し、自律的に対象を選ぶ徘徊型自爆機 | 禁制 |

「人間が最終ボタンを押す」だけでは第三種・第四種として認めない。候補が一瞬だけ提示される、根拠を確認できない、拒否権がない、通信遅延で中止不能といった構造は有効な人間判断ではない。

軍用UAVは、所有国、部隊、機体番号、管制主体、作戦指揮官、自律等級、通信喪失時行動、飛行・武器使用記録を登録する。個人名の名乗りは任意だが、実際に判断した人間と命令経路は調査可能でなければならない。

救難UAVは国連登録、専用IFF、武装禁止、観測装置制限、飛行記録公開、回収物申告を条件に保護する。救難機偽装は制度全体を崩す重大違反である。

## 長距離弾道ミサイル

長距離弾道ミサイルの禁制は、単に長距離だからではない。発射後に広域攻撃が自動進行し、現地の戦闘員・民間人・降伏・救難状況を確認せず、攻撃対象と被害範囲を限定できないためである。生物・化学兵器搭載の疑念、先制攻撃への圧力、事故時の越境被害も規制理由になる。

ゼア包囲戦争中盤の複合弾頭GFLBMは、地上施設、交通、人員、駐機機、離陸機、飛行中の航空機を一つの攻撃領域として自動探索・大量破壊する。人間が相手を具体的な対象として認識しないまま攻撃を進める点で、自律攻撃UAVと同じ禁忌の極に位置する。

## その他の禁止・制限

- 救難、降伏、休戦交渉、医療、国連共通通信への妨害は重大な禁忌とする。
- 大量チャフ散布は味方、救難、民間航空も妨害するため制限する。
- 攻撃命令の偽造、奪取UAVによる元所有国への攻撃、救難UAVの奪取を禁ずる。
- 核兵器は未製造とし、濃縮施設、反応設備、核物質輸送を国際管理下に置く。
- 大規模化学兵器・生物兵器・都市無差別破壊兵器を禁制とする。
- 反物質兵器は技術的に成立していない。

## 未確定事項

- 遠隔操縦者を飛行士とするか、「航空管制戦闘員」という別身分にするか。
- 半自律防空に認める例外と、通信喪失時の安全行動の範囲。
