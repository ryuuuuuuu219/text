# 通常戦闘規定

## 位置づけ

陸海空を問わず全戦闘員と軍事組織へ適用される現行の強制規定。航空騎士道法に含まれていた識別、降伏、捕虜、負傷者、脱出者、救難者の保護を一般化して引き継ぐ。

違反は軍法・国際法上の審査対象となる。名乗り、決闘、名誉などの任意慣習より常に優先する。

## 基本原則

1. 攻撃対象を戦闘員・軍事目標として識別する。
2. 攻撃を決定または中止できる人間へ、必要な情報、理解時間、権限を与える。
3. 判断根拠、命令経路、使用兵器、攻撃結果を後から再現できる形で記録する。
4. 降伏者、捕虜、負傷者、脱出者、救難者、医療・民間対象を保護する。
5. 攻撃後は実行者一人へ責任を集中させず、権限と知識に応じて組織全体を調査する。
6. 国家と軍は、合法な命令に従った個人を保護し、被害の説明・補償・再発防止を引き受ける。

この規定が求める「責任」とは、誰か一人を処罰できる状態ではない。人間が結果を予測し、選択し、中止でき、その過程を組織が検証して結果を引き受けられる状態を指す。

## 責任の種類

| 種類 | 問う内容 | 攻撃後の処理 |
|---|---|---|
| 因果責任 | どの行為・装備・情報が結果を生んだか | 事実関係の確定 |
| 判断責任 | 誰が何を根拠に攻撃を決定したか | 判断理由の説明と適法性審査 |
| 職務責任 | 誰に確認・中止・監督義務があったか | 義務履行の審査 |
| 法的責任 | 故意・過失・違法性があったか | 処罰、懲戒、免責 |
| 政治的責任 | 国家・軍が作戦を承認し維持したか | 公表、正当化、謝罪、辞任など |
| 賠償責任 | 被害を誰が回復するか | 補償、治療、遺族支援、復旧 |
| 再発防止責任 | 同じ結果をどう防ぐか | 装備、規則、教育、指揮系統の変更 |

## 責任の連鎖

| 段階 | 主な責任主体 |
|---|---|
| 戦争・作戦を開始する | 政府、戦時評議会、最高司令部 |
| 交戦規則を定める | 軍上層部、法務部門 |
| 目標情報を作る | 偵察、情報、管制部門 |
| 攻撃を承認する | 作戦指揮官、管制官 |
| 現場で最終確認する | パイロット、射手、UAVオペレーター |
| 兵器を設計・配備する | 開発者、試験機関、調達部門 |
| 被害を調査する | 軍法機関、独立調査機関、国際機関 |
| 被害を補償する | 国家、軍、国際機関 |

発射者や最寄りのオペレーターだけを責任者に指定しても、その者に十分な情報、理解時間、中止権限がなければ有効な人間判断とは認めない。

## 攻撃前の義務

- 対象、位置、所属、戦闘員性、攻撃許可を確認する。
- センサーの不確実性、民間人・友軍・保護対象の存在を確認する。
- 攻撃中止の条件と、中止命令が兵器へ届く範囲を把握する。
- 自動システムの推奨を覆す権限を、名目上ではなく実際に行使可能にする。
- 明白に違法な命令には照会、拒否、記録を行う。

## 保護対象

- 降伏意思を示した戦闘員・機体
- 捕虜、負傷者、脱出者、漂流者
- 救難機、医療機、民間機、国連機関
- 救難・降伏・休戦・医療・国連共通通信
- 武装を失い、戦闘から離脱する意思を明確に示した者

保護標章や救難信号の悪用は、保護制度全体を破壊する重大違反とする。

## 攻撃後の審査

### 適法な攻撃

合理的な識別と手順に基づく適法な攻撃では、判断者は行為と理由を説明する責任を負うが、撃墜したこと自体では処罰されない。国家と軍はその攻撃を公的行為として引き受け、個人を防御する。

### 合理的に回避できなかった誤認

当時利用可能な情報から誤認を避けられなかった場合、個人を処罰しないことがある。ただし調査、公表、補償、装備・手順の改善、同条件での攻撃停止などの制度的責任は残る。

### 過失

必要な識別を省略した、警告を無視した、中止可能なのに続行した場合は懲戒・刑事責任を問う。虚偽情報を作った部門、欠陥を知りながら配備した部門、過剰な戦果を要求した上層部も同時に審査する。

### 意図的な違法攻撃

民間対象、降伏者、脱出者、救難者だと認識しながら攻撃した場合、実行者と命令者の双方を問う。命令への服従だけでは自動的に免責されない。

## 記録義務

- センサーと識別情報
- 警告、応答、降伏、攻撃中止通信
- 命令・承認・拒否の時刻と主体
- 自動システムが提示した候補と、人間が選択した内容
- 使用兵器、指定目標、目標喪失後の挙動
- 命中、誤認、民間被害、救難結果

記録の目的は犯人を一人選ぶことではなく、攻撃判断と結果の因果関係を再現することである。
