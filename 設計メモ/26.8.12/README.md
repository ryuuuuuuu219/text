# 26.8.12 設計正本

企画・世界設定・戦局・人物・会話規則を、実装や執筆から参照しやすい単位へ整理した正本候補である。

本プロジェクトの中核は、**プレイヤーが設計した飛行機**と**成長・消耗するパイロット**の組み合わせが、自動空戦と継続戦局へ影響し、プレイごとに固有の部隊史を生むことである。

Codexによる生成はゲーム実行中には行わない。開発中に会話、人物、特殊イベント、ストーリー断片の候補を公開前に生成し、人間が検品・採用したプリセットだけを製品へ収録する。

## 設計上の優先順位

1. 機体を設計する。
2. パイロットを配属し、実戦を通して成長させる。
3. 機体とパイロットの組み合わせが自動空戦の判断と結果を変える。
4. 戦果、損害、負傷、死亡、補充が継続戦局へ蓄積する。
5. 蓄積した記録から、そのキャンペーン固有の部隊史が生まれる。

## 記述上の区分

- **確定**：参照元で確定事項として明記されている、または複数資料で一貫している内容。
- **初期仕様**：MVPや初期実装で採用する内容。将来拡張とは分けて扱う。
- **候補**：比較案・分岐案・未決定事項。確定設定として外部へ出さない。
- **未確定**：決定が必要だが、現時点で根拠がない内容。

参照元に残る `B国` は初期企画時の仮称であり、現在の戦争設定ではゼア過激派を開戦主体とする。地図上の `B` は別途ベティアを指すため、混同しない。

## 生成AIの位置づけ

- 公開前の制作支援に限定する。
- 生成結果は設定整合性、事実関係、表現、権利、対象年齢を人間が検品する。
- 実行時は条件に一致する採用済みプリセットを選択・再生する。
- 勝敗、戦果、死亡、成長、人物関係、戦局分岐はゲームシステムが決定する。

## 正本化で残る作業

- 各国・都市・空母・人物の正式名を決める。
- 主人公の開始勢力を本当に乱数決定するか、選択式にするかを決める。
- UAV登場を段階導入にするか、物語開始時から有人・無人混成にするかを決める。
- 焦土作戦を固定イベントにするか、条件分岐イベントにするかを決める。
