# カメラ・観戦対象

## 基本表示

戦闘は俯瞰カメラで観戦する。プレイヤーが任意の機体を選ぶと、その機体を観戦対象とし、周辺通信を優先表示する。

別戦域で発生した会話は通信ログへ保存し、戦闘後に読み返せるようにする。カメラ外の発言もログへ保存する。

## カメラ操作

初期位置は `(0, 300, -1000)`、原点からの距離は約1044とする。カメラは原点方向を向く約16.7度の俯角で固定し、プレイヤーによる回転操作は設けない。

ズーム距離は100、200、500、1000の4段階とし、位置は `(0, 300, -1000).normalized × ズーム距離` で求める。ズーム操作時は右ドラッグによる移動量を破棄し、選択した距離の基準位置へ戻す。ズーム段階は配列の末尾と先頭を接続した循環構造とする。

メニューボタン直下の `(0, 80)` から `(100, 110)` に白枠の矩形ボタンを横並びで配置する。左側の `+` はズームイン、右側の `-` はズームアウトを表す。ボタン内部は通常時に透過し、マウスオーバー時だけ薄い白色を表示する。

右クリックを押しながらドラッグすると、カメラの `transform.forward` に直交する平面へマウス位置を投影してカメラを平行移動する。カメラ回転は変更しない。地形の断端をカメラ内へ入れないため、16:9表示を基準として視錐台が地形外へ出る直前で左右移動を制限し、カメラ高度は1以上に制限する。

地形は原点中心の12000×12000とする。垂直画角60度、Far Clip 5000、最短ズーム距離100に必要な理論最小値約10264へ、右ドラッグ用の余裕を加えた寸法である。

## ミッション選択

出撃候補アイコンの近辺に任務の種類を常時明示する。詳細は[ミッション選択](../../02_ミッション進行/00_ミッション選択/ミッション選択.md)を参照する。

## 戦闘中の共通画面

PC操作を前提とし、索敵・識別と交戦では次の配置を共通使用する。

座標は1024×768を基準解像度とし、画面左上を原点 `(0, 0)`、右方向をX正、下方向をY正とする。矩形範囲は左上座標と右下座標で表す。

| UI | 内部表示 | 外形・表示仕様 | 矩形範囲 |
|---|---|---|---|
| メニューボタン | `≡` | 矩形内の内接円 | `(0, 0)`～`(80, 80)` |
| ズームイン | `+` | 白枠の矩形 | `(0, 80)`～`(50, 110)` |
| ズームアウト | `-` | 白枠の矩形 | `(50, 80)`～`(100, 110)` |
| 情報ボードボタン | `i` | 青色の内接円 | `(944, 0)`～`(1024, 80)` |
| 展開中情報ボード | 情報項目 | 垂直スクロールビュー。白枠、不透明度0.3。幅10のスクロールバーを右側に配置 | `(400, 80)`～`(1024, 600)` |
| ミニマップ | 飛行隊、目標、母艦のアイコン | 矩形 | `(0, 528)`～`(240, 768)` |
| 母艦注視ボタン | 家マーク | 矩形 | `(242, 648)`～`(322, 728)` |
| 飛行隊一覧 | 飛行隊項目 | 垂直スクロールビュー。1列の高さは30 | `(350, 608)`～`(550, 768)` |
| 帰還指示 | 帰還指示テキスト | 矩形テキストボタン | `(560, 688)`～`(600, 768)` |
| カメラビュー | 機体、地形、吹き出し | 他のUIに覆われていない画面領域 | `(0, 0)`～`(1024, 768)` |

メニューボタンを押すとゲームを一時停止する。情報ボードは初期状態では格納し、情報ボードボタンで展開する。ミニマップ上の飛行隊、目標、母艦を選択すると俯瞰カメラを移動する。飛行隊一覧から飛行隊を選択すると指示用プルダウンを展開する。

## 場面ごとの表示

| 場面 | 表示 |
|---|---|
| 戦闘 | 俯瞰カメラ。機体上部の吹き出しと再確認可能なログ |
| ブリーフィング／デブリーフィング | 作戦・戦果ボード、または会議室俯瞰。表示を切替可能 |
| 個人的な相談 | 人物名と本文だけの会話ログ。立ち絵・背景差分なし |
| 戦局まとめ | 地図グリッド、支配圏、画面下字幕、記録映画風ナレーション |
| ミッション選択 | グリッド上へ出撃候補を配置。候補付近に任務種別を明示し、未回収者がいれば前回座標を保持 |

格納庫、食堂、私室、基地内部、人物図鑑、立ち絵鑑賞などの専用画面は初期仕様では作らない。出撃前会話はブリーフィング末尾、戦績画面はデブリーフィングのボードへ統合する。
