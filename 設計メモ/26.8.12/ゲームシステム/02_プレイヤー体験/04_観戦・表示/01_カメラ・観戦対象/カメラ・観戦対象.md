# カメラ・観戦対象

## 基本表示

戦闘は俯瞰カメラで観戦する。プレイヤーが任意の機体を選ぶと、その機体を観戦対象とし、周辺通信を優先表示する。

別戦域で発生した会話は通信ログへ保存し、戦闘後に読み返せるようにする。カメラ外の発言もログへ保存する。

## カメラ操作

初期位置は `(0, 300, -1000)`、原点からの距離は約1044とする。カメラは原点方向を向く約16.7度の俯角で固定し、プレイヤーによる回転操作は設けない。

ズーム距離は100、200、500、1000、2000、5000、7500、10000、12000の9段階とし、位置は `(0, 300, -1000).normalized × ズーム距離` で求める。ズーム操作時は右ドラッグによる移動量を破棄し、選択した距離の基準位置へ戻す。ズーム段階は配列の末尾と先頭を接続した循環構造とする。

メニューボタン直下の `(0, 80)` から `(100, 110)` に白枠の矩形ボタンを横並びで配置する。左側の `+` はズームイン、右側の `-` はズームアウトを表す。ボタン内部は通常時に透過し、マウスオーバー時だけ薄い白色を表示する。

右クリックを押しながらドラッグすると、カメラの `transform.forward` に直交する平面へマウス位置を投影してカメラを平行移動する。カメラ回転は変更しない。左右移動は地形中心から13900以内に制限し、カメラ高度は1以上に制限する。

地形は原点中心の28000×28000とする。垂直画角60度、Far Clip 17000とする。1024×768の4:3表示におけるFar Clip位置の視錐台幅約26173へ余裕を加えた寸法である。

## ミッション選択

出撃候補アイコンの近辺に任務の種類を常時明示する。詳細は[ミッション選択](../../02_ミッション進行/00_ミッション選択/ミッション選択.md)を参照する。

## 戦闘中の共通画面

PC操作を前提とし、索敵・識別と交戦では次の配置を共通使用する。

座標は1024×768を基準解像度とし、画面左上を原点 `(0, 0)`、右方向をX正、下方向をY正とする。矩形範囲は左上座標と右下座標で表す。

| UI | 内部表示 | 外形・表示仕様 | 矩形範囲 |
|---|---|---|---|
| メニューボタン | `≡` | 矩形内の内接円 | `(0, 0)`～`(80, 80)` |
| ズームイン | `+` | 白枠の矩形 | `(0, 80)`～`(50, 110)` |
| ズームアウト | `-` | 白枠の矩形 | `(50, 80)`～`(100, 110)` |
| 情報ボードボタン | `i` | 青色の内接円 | `(944, 0)`～`(1024, 80)` |
| 展開中情報ボード | 情報項目 | 垂直スクロールビュー。白枠、不透明度0.3。幅10のスクロールバーを右側に配置 | `(400, 80)`～`(1024, 600)` |
| ミニマップ | 飛行隊、目標、母艦のアイコン | 200×200の正方形 | `(0, 568)`～`(200, 768)` |
| 母艦注視ボタン | 家マーク | 矩形 | `(202, 648)`～`(282, 728)` |
| 飛行隊一覧 | 飛行隊項目 | 垂直スクロールビュー。1列の高さは30 | `(310, 608)`～`(510, 768)` |
| 構成機選択 | 選択中の飛行隊に所属する機体 | 飛行隊一覧と同寸法の垂直スクロールビュー。1列の高さは30 | `(510, 608)`～`(710, 768)` |

| 帰還中 | `帰還中` | 目標選択ボタン領域の左から5番目 | `(960, 650)`～`(1020, 768)` |

メニューボタンを押すとゲームを一時停止する。情報ボードは初期状態では格納し、情報ボードボタンで展開する。ミニマップ上の飛行隊、目標、母艦を選択すると俯瞰カメラを移動する。飛行隊一覧から飛行隊を選択すると、その飛行隊を目標基準の指示対象とし、構成機選択スクロールビューへ所属機を表示する。構成機を選択すると、その機体を観戦対象とする。指示用プルダウンは設けない。

目標選択は、構成機選択スクロールビューの右へ10空けた `(720, 650)`～`(1020, 768)` を横5等分した常設ボタンで操作する。選択肢は左から「対正面」「対近距離」「対遠距離」「カウンター」「帰還中」とし、選択中の基準を強調表示する。選択した基準は飛行隊の全所属機へ反映し、次のAI更新で目標を再評価する。「帰還中」を選択した機体は現在の交戦目標を解除する。飛行隊が未選択の場合は5ボタンを無効表示とし、目標基準表示には未選択と表示する。目標選択処理の詳細は[自動空戦AI設計](../../../01_ゲームシステム/06_自動空戦/自動空戦AI設計.md)を参照する。

ミニマップを240×240から200×200へ縮小し、母艦注視ボタン以降の下部UIを40左へ移動する。これにより目標選択領域の300幅を維持しながら、右端を1024×768の基準解像度内へ収める。

## 場面ごとの表示

| 場面 | 表示 |
|---|---|
| 戦闘 | 俯瞰カメラ。機体上部の吹き出しと再確認可能なログ |
| ブリーフィング／デブリーフィング | 作戦・戦果ボード、または会議室俯瞰。表示を切替可能 |
| 個人的な相談 | 人物名と本文だけの会話ログ。立ち絵・背景差分なし |
| 戦局まとめ | 地図グリッド、支配圏、画面下字幕、記録映画風ナレーション |
| ミッション選択 | グリッド上へ出撃候補を配置。候補付近に任務種別を明示し、未回収者がいれば前回座標を保持 |

格納庫、食堂、私室、基地内部、人物図鑑、立ち絵鑑賞などの専用画面は初期仕様では作らない。出撃前会話はブリーフィング末尾、戦績画面はデブリーフィングのボードへ統合する。
