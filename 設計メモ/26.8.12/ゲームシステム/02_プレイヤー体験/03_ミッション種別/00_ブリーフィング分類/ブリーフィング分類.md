# ブリーフィング分類

## 分類の目的

ミッション種別とは別に、作戦開始時点でプレイヤーへ提示できる情報の状態を三パターンへ分類する。

| 分類 | 適用条件 | 主な表示 |
|---|---|---|
| パターン1：目標・座標が明確 | 作戦目標または救出対象と座標が確定している | 距離、ETA、想定敵戦力、空・陸・海の傾向 |
| パターン2：哨戒任務 | 明確な敵目標がなく、指定空域の巡回から開始する | 短い任務説明のみ |
| パターン3：スクランブル | 敵接近などへ即時対応し、詳細確認より出撃を優先する | 現時点で判明している敵戦力の傾向 |

同じミッション種別でも、発生時点の情報によって分類は変わる。分類は勝敗条件や任務原型を置き換えず、ブリーフィング表示だけを決める。

## 分類の決定順

1. 救出対象または作戦目標と座標が確定している場合はパターン1とする。
2. 即時出撃が必要で、詳細情報の整理を待てない場合はパターン3とする。
3. 明確な敵目標がなく、空域巡回から開始する場合はパターン2とする。
4. いずれにも該当しない場合は、目標と座標の確定状況を基にパターン1または3へ寄せる。

## ミッション中の変化

パターン2の哨戒中に不明機や敵エースへ接触しても、開始時のブリーフィング分類は変更しない。接触後は戦局情報ボードへ緊急目標を追加する。

パターン3で出撃した後に目標と座標が完全確認された場合も、過去のブリーフィングをパターン1へ書き換えない。確認済み情報として戦局情報ボードを更新する。

表示内容の詳細は[ブリーフィング](../../02_ミッション進行/01_ブリーフィング/ブリーフィング.md)を参照する。

## 現在の対応表

| ミッション候補 | 基本分類 | 条件による変更 |
|---|---|---|
| 通常哨戒 | パターン2 | 接触後も開始時分類は変更せず、緊急目標を追加 |
| 不明機接触 | パターン3 | 哨戒中に発生した場合はパターン2のまま進行 |
| 国境の強行偵察 | パターン3 | 対象と座標を事前特定済みならパターン1 |
| 欺瞞邀撃 | パターン3 | 哨戒中の接触ならパターン2のまま進行 |
| 敵エース接触 | パターン3 | 哨戒中の遭遇ならパターン2のまま進行 |
| 空母攻撃機隊迎撃 | パターン3 | 編隊位置と迎撃点が確定済みならパターン1 |
| 幹線道路・首都・要塞・前線基地・火薬庫・対空陣地への攻撃 | パターン1 | なし |
| 大規模空戦 | パターン3 | 事前計画された戦域投入ならパターン1 |
| 集合地点急行 | パターン1 | 座標未確定の緊急出撃ならパターン3 |
| 要人護衛・運河占領・落下傘部隊護衛・救難・避難船団 | パターン1 | なし |
| 資源採掘 | パターン1 | 採掘中の敵襲はブリーフィングを挟まず緊急目標を追加 |
| UAV関連 | 基礎となる任務に従う | UAVであること自体は分類条件にしない |
