# MVPと開発順序

## MVPの目的

**機体設計とパイロット差によって戦闘結果が変わり、その差が次の戦局へ残るか**を先に検証する。

## MVP仕様

| 項目 | 仕様 |
|---|---|
| 空母 | 一隻、自動航行と耐久のみ |
| 味方 | パイロット三人、設計可能な機体三機 |
| 敵 | 一般機編隊と敵エース一人 |
| 任務 | 迎撃、護衛 |
| 戦術 | 慎重、標準、積極 |
| パイロット値 | 名声、性格、正G耐性、負G耐性 |
| 戦闘 | 簡易目標選択、離脱、撃墜を自動処理 |
| 観戦 | 俯瞰カメラ、機体選択、通信表示 |
| 回収 | 脱出後、制限時間内に回収 |
| 機体設計 | エンジン、主翼、燃料、兵装の最小構成 |
| 成長 | 能力、機体習熟、疲労、負傷を任務後に更新 |
| 戦局 | 敵味方戦力と損害を三作戦以上継続 |
| 会話 | 検品済み固定プリセットのみ |
| 敵エース | 放置すると空母を攻撃し、高名声機に誘引される |

## 評価項目

- 高名声者を出す利益と危険が両立するか。
- 敵エースを誰に担当させるかが重要か。
- 回収のため戦闘を中断する価値があるか。
- 性格と戦術方針の差が観戦だけで読めるか。
- 固定会話でも人物差と因縁を感じられるか。

## 開発順序

1. 機体構成、重量、推力、燃料、兵装と性能計算。
2. パイロット能力、性格、機体習熟、疲労。
3. 自動発艦、索敵、交戦、離脱、撃墜、帰還。
4. 任務割当、戦術方針、名声ヘイト、敵エース。
5. 戦果・損害・成長を次作戦へ引き継ぐ戦局更新。
6. 脱出、救難、回収、負傷、回復、喪失。
7. 俯瞰観戦、検品済み会話プリセット、通信ログ。
8. 複数戦域、空母移動、補給、人物関係、因縁。

公開前プリセット制作は並行可能だが、MVP成立条件には含めない。実行時AI接続は開発順序から除外する。

## 中核定義

名声は能力値、敵ヘイト、決闘、会話、空母防衛をつなぐ。敵エースとの決闘は演出ではなく、空母への攻撃を遅らせる防衛機構である。
