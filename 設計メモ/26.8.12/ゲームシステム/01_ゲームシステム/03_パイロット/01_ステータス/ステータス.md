# パイロットのステータス

パイロットは基本的に個別機体と対応して育成する。ゲームシステム上は航空隊を構成する人的戦力枠である。

## 操縦入力

| ステータス | 内容 |
|---|---|
| 旋回時目標AOA | 旋回時に目標とする迎角。状況と状態により変動する |
| 最低速度認識 | 失速を認識し、AOAを抑え始める速度閾値 |

## 生命力

| ステータス | 内容 |
|---|---|
| 脱出 | 撃墜時の確率脱出判定に使う |
| 長期スタミナ | 飛行時間で緩やかに減少し、視野へ補正する |
| 短期スタミナ最大値 | G負荷へ耐えられる短期的な余力 |
| 短期スタミナ回復量 | 時間経過による回復量 |
| 短期スタミナ閾値 | 操縦入力への大きな下方補正が始まる境界 |
| 割合・デバフ特性 | スタミナ減少割合に対するデバフ傾斜。基本形は `y=-ax` |
| 正負G耐性閾値 | スタミナ減少が始まる正G・負Gの境界 |
| G・スタミナ減少特性 | G負荷に対する短期スタミナ減少量 |

長期スタミナは機体のロール精度の影響を受ける。

## 視野

| ステータス | 内容 |
|---|---|
| 索敵半径 | パイロット自身が敵を発見できる範囲 |
| 射撃開始距離比 | 武装射程に対して射撃を開始する距離の割合 |

## 熟練度

熟練度が持つ性能補正はダメージ補正だけとする。武装側の固定ダメージへ乗算し、機体の速度、HP、装甲は変化させない。

## 著名度

著名度は名声と同じ値を指す。敵の注目、決闘、味方士気、二つ名候補の条件へ使用する。
