# ステータスの計算方法

## 基本計算

| 出力 | 基本式・判定 |
|---|---|
| 総重量 | 全部品重量の合計 |
| 有効翼面積 | 主翼と、揚力へ寄与する補助翼の翼面積合計 |
| 翼面荷重 | 総重量 ÷ 有効翼面積 |
| HP | 部品HP合計 × 胴体HP係数 × 防御率 |
| 分解速度 | 基準最高速度 × 全部品中で最低の安全率 |
| 空気抵抗 | 投影面積、空気粘性、速度から計算 |
| 最高速度 | 推力と空気抵抗が釣り合う速度を求める |
| 加速力 | 推力重量比を基礎値とする |
| 失速速度 | 翼面荷重を基礎値とする |
| ピッチ性能曲線 | 翼面荷重、動翼の性能曲線、補助翼補正を合成する |
| ロール性能 | 動翼性能、主翼長、エンジン配置を合成する |

最高速度はUI用に事前計算する。最高速度計算では重力の影響を考慮しない。

## 計算上の固定事項

- 防御率はHPへ乗算する。
- ピッチ性能曲線は二次関数を基本候補とする。
- エルロンとエレベーターは区別せず、単一の「動翼」として計算する。
- 燃料消費による重量減少と性能変化は計算しない。
- 部品単位で確定できる値は、機体完成時より前に計算・保存する。

具体的な係数、単位変換、上下限はFM検証後に確定する。
