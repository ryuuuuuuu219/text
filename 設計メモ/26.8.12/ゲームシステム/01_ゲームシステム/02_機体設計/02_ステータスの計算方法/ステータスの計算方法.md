# ステータスの計算方法

## 基本計算

| 出力 | 基本式・判定 |
|---|---|
| 総重量 | 全部品重量の合計 |
| 有効翼面積 | 主翼と、揚力へ寄与する補助翼の翼面積合計 |
| HP | 部品HP合計 × 胴体HP係数 × 防御率 |
| 分解速度 | 理想急降下平衡速度 × 全部品中で最低の安全率 |
| 空気抵抗 | 投影面積、空気粘性、速度から計算 |
| 水平飛行平衡速度 | 通常推力と前進抗力が釣り合う速度を求める |
| 理想急降下平衡速度 | 機首・速度・重力が鉛直下向きに一致し、通常推力＋重力と前進抗力が釣り合う速度を求める |
| 加速力 | 推力重量比を基礎値とする |
| ピッチ性能曲線 | 主翼が持つ4つの性能値から三次関数を生成する |
| ロール性能 | 動翼性能、主翼長、エンジン配置を合成する |

水平飛行平衡速度と理想急降下平衡速度はUI用に事前計算する。水平飛行平衡速度では進行方向の重力を0とし、理想急降下平衡速度では重力加速度9.81 m/s²を推力と同方向へ加える。

```text
水平飛行平衡速度 = sqrt(総推力 / (抗力係数 × 空気粘性 × 前面投影面積)) × 速度係数
理想急降下平衡速度 = 水平飛行平衡速度 × sqrt((加速性能 + 重力加速度) / 加速性能)
分解速度 = 理想急降下平衡速度 × 最小実効安全率
```

## 計算上の固定事項

- 防御率はHPへ乗算する。
- ピッチ性能曲線は三次関数で定義する。
- ピッチ性能の4値は主翼だけが保持する。動翼と補助翼はピッチ性能へ関与しない。
- エルロンとエレベーターは区別せず、ロール性能を決める単一の「動翼」として計算する。
- 燃料消費による重量減少と性能変化は計算しない。
- 部品単位で確定できる値は、機体完成時より前に計算・保存する。

具体的な係数、単位変換、上下限はFM検証後に確定する。

## ピッチ性能の三次関数

ピッチ性能を次の三次関数とする。

```text
f(v) = av³ + bv² + cv + d
```

主翼には係数を直接保存せず、次の4値を保存する。

- 低速性能 `C`
- 最大性能 `M`
- 最適速度 `P`
- 操舵限界速度 `X`

係数 `a,b,c,d` は次の4条件を満たすように生成する。

```text
f(0) = C
f(P) = M
f'(P) = 0
f(X) = 0
```

## 入力検証

- `0 < P < X` を必須とする。
- 生成後に `f''(P) < 0` を確認し、`P` が極大点であることを保証する。
- 使用速度域 `0 <= v <= X` で、`P` より前は上昇、`P` より後は下降することを確認する。
- 使用速度域で意図しない負値や別の極大値が出る組み合わせは無効とする。
- `v >= X` のピッチ性能は0にクランプし、三次関数の外挿による再上昇や負値をFMへ渡さない。
