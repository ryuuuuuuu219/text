# ステータスからFMへの変換

設計画面で確定した性能ステータスを、実行時のフライトモデル（FM）が使用する値へ変換する境界を定義する。

| 設計ステータス | FMでの用途 |
|---|---|
| 総重量 | 推力に対する加速度、慣性、旋回応答 |
| 最高速度 | 水平加速の上限目安。超過時は簡略空気抵抗を増やす |
| 加速力 | エンジン出力から前進速度へ至る応答 |
| 失速速度 | AOA抑制、失速状態への移行判定 |
| 分解速度 | 速度超過による構造破壊判定 |
| ピッチ性能曲線 | 4つの部品性能から生成した三次関数を評価し、現在速度に応じたピッチ角速度上限へ変換 |
| ロール性能 | ロール角速度上限 |
| ロール精度 | 操縦入力誤差とパイロット疲労への補正 |
| HP | 被弾による戦闘不能判定 |
| 作戦時間 | 作戦継続・帰投開始判定 |

## 境界

- UI用最高速度は、推力と抗力の均衡点として計算済みの値を使う。
- UI用最高速度の計算では重力を無視するが、実行時FMの通常飛行まで無重力にする意味ではない。
- 作戦時間が0になると帰投行動へ移る。FMは燃料0でも帰投飛行を継続する。
- パイロット能力は機体の物理ステータスを書き換えず、入力、判断、スタミナ、武装ダメージ補正として別に適用する。

## ピッチ性能の適用

1. 動翼の低速性能 `C`、最大性能 `M`、最適速度 `P`、操舵限界速度 `X` から三次関数を生成する。
2. 現在速度 `v` を関数へ入力し、基礎ピッチ性能 `f(v)` を得る。
3. 翼面荷重と補助翼の性能補正を適用する。
4. 得られた値をFMのピッチ角速度上限へ変換する。
5. `v >= X` ではピッチ性能を0に固定する。

三次関数は部品または機体完成時に生成・検証して保存し、毎フレーム係数を再計算しない。

## 物理演算の範囲

ベロシティベクトル、AOA、旋回時減速、推力、重力、高度制限、海面接触、揚力の省略、簡略抗力、および姿勢角制限は[空戦物理演算](../05_飛行物理演算設計/01_空戦物理演算/空戦物理演算.md)を正本とする。
