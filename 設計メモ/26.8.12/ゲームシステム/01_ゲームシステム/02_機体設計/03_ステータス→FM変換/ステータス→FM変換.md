# ステータスからFMへの変換

設計画面で確定した性能ステータスを、実行時のフライトモデル（FM）が使用する値へ変換する境界を定義する。

| 設計ステータス | FMでの用途 |
|---|---|
| 総重量 | 推力に対する加速度、慣性、旋回応答 |
| 水平飛行平衡速度 | 通常推力と速度二乗型の前進抗力が釣り合う基準速度 |
| 理想急降下平衡速度 | 通常推力＋重力と前進抗力が釣り合う急降下時の基準速度 |
| 分解速度 | Rigidbody速度の現行上限。将来は超過時の構造破壊判定に使用する |
| 加速力 | エンジン出力から前進速度へ至る応答 |
| ピッチ性能曲線 | 主翼の4つの性能値から生成した三次関数を評価し、現在速度に応じたピッチ角速度上限へ変換 |
| ロール性能 | ロール角速度上限 |
| ロール精度 | 操縦入力誤差とパイロット疲労への補正 |
| HP | 被弾による戦闘不能判定 |
| 作戦時間 | 作戦継続・帰投開始判定 |

## 境界

- UIには水平飛行平衡速度と理想急降下平衡速度を計算済みの値として渡す。
- 水平飛行平衡速度では進行方向の重力を0として扱い、理想急降下平衡速度では重力を推力と同方向へ加える。
- 作戦時間が0になると帰投行動へ移る。FMは燃料0でも帰投飛行を継続する。
- パイロット能力は機体の物理ステータスを書き換えず、入力、判断、スタミナ、武装ダメージ補正として別に適用する。

## ピッチ性能の適用

1. 主翼の低速性能 `C`、最大性能 `M`、最適速度 `P`、操舵限界速度 `X` から三次関数を生成する。
2. 現在速度 `v` を関数へ入力し、ピッチ性能 `f(v)` を得る。
3. 得られた値をFMのピッチ角速度上限へ変換する。
4. `v >= X` ではピッチ性能を0に固定する。

動翼と補助翼によるピッチ性能補正は行わない。

三次関数は部品または機体完成時に生成・検証して保存し、毎フレーム係数を再計算しない。

## 物理演算の範囲

ベロシティベクトル、AOA、旋回時減速、推力、重力、高度制限、海面接触、揚力の省略、簡略抗力、および姿勢角制限は[空戦物理演算](../05_飛行物理演算設計/01_空戦物理演算/空戦物理演算.md)を正本とする。
