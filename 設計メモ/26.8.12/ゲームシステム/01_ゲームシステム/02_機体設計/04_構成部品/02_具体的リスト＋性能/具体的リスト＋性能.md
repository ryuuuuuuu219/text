# 具体的リスト＋性能

部品は固定性能の生産品と、ランダム性能の鹵獲品に分かれる。

## 表示例

```text
主翼A
重量 320kg
長さ 4.2m
幅 1.3m
厚さ 0.14m
HP 280
ハードポイント 2
材質品質 1.06
接合品質 0.91
```

## 部品別項目

| 部品 | UI公開値 | 主な内部変数・備考 |
|---|---|---|
| 胴体 | HP係数、形状、直径、容積 | 丸み、頂点数、投影面積。形状候補は円柱・四角柱 |
| 主翼 | 翼面積、ハードポイント数、最大合計重量、種類、容積 | 角度、長さ、厚さ、幅。デルタ翼など尾翼一体型を考慮 |
| フラップ | 使用時失速速度係数、使用時旋回速度係数 | 使用状態を持つ |
| 動翼 | ピッチ性能曲線、ロール性能 | エルロン・エレベーターを区別しない |
| 補助翼 | ピッチ補正、ロール補正、尾翼／カナード | 角度、長さ、厚さ、幅。主翼種類によりスロットを使えない場合がある |
| エンジン | 取付位置、推力 | 胴体前後または主翼。プロペラ枚数と間隔はロール精度へ反映 |
| 燃料タンク | 格納位置、体積 | 品質なし。格納先の容積を超える場合は搭載不可 |
| 装甲 | 防御率、装甲重量 | 任意搭載。防御率はHPへ乗算 |
| ハードポイント | 対応兵装種類、最大重量 | 爆弾、ロケット、ガンポッド、ミサイル |

## 入手区分

- 生産：固定性能のプリセット部品。
- 鹵獲：敵機撃墜後に確率ドロップするランダム性能部品。ミッション完了時までに回収できた場合だけ取得する。
