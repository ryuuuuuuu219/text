# 部品ごとの役割

| 部品 | 役割 |
|---|---|
| 胴体 | HP係数、形状、投影面積、内部容積の基準 |
| 主翼 | 翼面積、ハードポイント、格納容積、翼形式を決める |
| フラップ | 使用時の失速速度と旋回性能を補正する |
| 動翼 | ピッチ性能曲線とロール性能を決める |
| 補助翼 | ピッチ・ロールを補正する。尾翼またはカナードを選ぶ |
| エンジン | 推力と取付位置を決める |
| 燃料タンク | 格納先と体積から作戦時間を決める |
| 装甲 | 重量と引き換えにHPへ乗算する防御率を与える |
| ハードポイント | 搭載できる兵装種類と最大重量を制限する |
| 補助装備 | センサーなど、基本部品外の機能を追加する |

エルロン、エレベーターなどの部位名称はUIで隠蔽し、混同した「動翼」として簡略化する。
