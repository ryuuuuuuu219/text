# 性能ステータス

機体設計画面でプレイヤーへ公開する完成機の性能値を定義する。部品の寸法や描画用変数とは分離する。

## 完成機の公開ステータス

| ステータス | 内容 |
|---|---|
| 総重量 | 全構成部品、装甲、兵装、燃料タンクの重量合計 |
| HP | 部品HP、胴体HP係数、防御率から求める耐久値 |
| 翼面荷重 | 総重量を有効翼面積で割った値 |
| 最高速度 | 推力と空気抵抗が釣り合い、加速が止まる速度 |
| 加速力 | 推力重量比を基礎とする加速性能 |
| 失速速度 | 翼面荷重を基礎とする失速境界 |
| 分解速度 | 最も低い部品安全率によって制限される速度 |
| ピッチ性能曲線 | 速度ごとの機首上げ・下げ性能 |
| ロール性能 | 動翼、主翼長、エンジン配置から求める横転性能 |
| ロール精度 | 入力どおりのロールを維持できる精度 |
| 作戦時間 | 燃料タンク体積から決まる戦闘参加可能時間 |
| ハードポイント | 搭載可能数、種類、最大合計重量 |

## 部品共通の公開ステータス

- 重量
- HP
- 安全率
- 部品固有性能
- 材質品質
- 接合品質

## 非公開変数

描画や内部計算には使うが、通常UIには表示しない。

- 寸法、角度、丸み、頂点数
- 投影面積
- 空気粘性
- 重力
- エンジン間隔などの配置値
