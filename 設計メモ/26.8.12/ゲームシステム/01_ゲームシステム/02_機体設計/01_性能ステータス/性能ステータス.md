# 性能ステータス

機体設計画面でプレイヤーへ公開する完成機の性能値を定義する。部品の寸法や描画用変数とは分離する。

## 完成機の公開ステータス

| ステータス | 内容 |
|---|---|
| 総重量 | 全構成部品、装甲、兵装、燃料タンクの重量合計 |
| HP | 部品HP、胴体HP係数、防御率から求める耐久値 |
| 水平飛行平衡速度 | 水平飛行の理想条件で、通常推力と空気抵抗が釣り合う速度 |
| 理想急降下平衡速度 | 鉛直急降下の理想条件で、通常推力＋重力と空気抵抗が釣り合う速度 |
| 分解速度 | 理想急降下平衡速度と機体の最小実効安全率から求める構造限界速度 |
| 加速力 | 推力重量比を基礎とする加速性能 |
| ピッチ性能曲線 | 低速性能、最大性能、最適速度、操舵限界速度から生成する三次関数 |
| ロール性能 | 動翼、主翼長、エンジン配置から求める横転性能 |
| ロール精度 | 入力どおりのロールを維持できる精度 |
| 作戦時間 | 燃料タンク体積から決まる戦闘参加可能時間 |
| ハードポイント | 搭載可能数、種類、最大合計重量 |

## 部品共通の公開ステータス

- 重量
- HP
- 安全率
- 部品固有性能
- 材質品質
- 接合品質

## ピッチ性能曲線の公開値

主翼は三次関数の係数を直接表示せず、次の4値を部品性能として持つ。

| 値 | 記号 | 内容 |
|---|---|---|
| 低速性能 | `C` | 速度0におけるピッチ性能 `f(0)` |
| 最大性能 | `M` | 最適速度におけるピッチ性能 `f(P)` |
| 最適速度 | `P` | 最大性能を発揮する速度 |
| 操舵限界速度 | `X` | ピッチ性能が0になる速度 `f(X)` |

UIでは「低速性能・最大性能・最適速度・操舵限界速度」を表示し、三次関数の係数 `a,b,c,d` は非公開とする。

## 非公開変数

描画や内部計算には使うが、通常UIには表示しない。

- 寸法、角度、丸み、頂点数
- 投影面積
- 空気粘性
- 重力
- エンジン間隔などの配置値
