# 兵装リスト

## 登録項目

| 項目 | 内容 |
|---|---|
| ID | セーブデータと実装で使用する不変ID |
| 表示名 | UIで表示する名称 |
| 種別 | 機銃、機関砲、ロケット、爆弾、ミサイル、ガンポッドなど |
| 弾種ID | 使用する弾種への参照 |
| 固定ダメージ | 熟練度補正前の基礎値 |
| 射程・弾速 | 射撃開始と命中判定に使用 |
| 発射間隔 | 連射性能 |
| 弾薬数 | 一出撃で使用可能な数 |
| 本体重量 | 兵装本体の重量 |
| 弾薬重量 | 搭載弾薬の重量 |
| 対応ハードポイント | 搭載可能な種類 |
| 入手区分 | 固定性能の生産品、またはランダム性能の鹵獲品 |
| 法規区分 | 通常、制限、禁止など |

## 具体的リスト

| ID | 表示名 | 種別 | 弾種ID | 固定ダメージ | 射程 | 弾速 | 弾薬数 | 重量 | 入手区分 | 状態 |
|---|---|---|---|---:|---:|---:|---:|---:|---|---|
| 未設定 | 未設定 | 未設定 | 未設定 | 0 | 0 | 0 | 0 | 0 | 未設定 | 候補 |

数値は戦闘検証後に確定する。世界観上の兵器名や誘導方式は `世界観/06_技術・兵器` を参照する。
