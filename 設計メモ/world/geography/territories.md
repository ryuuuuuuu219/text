# 領土と管轄

## レイの飛び地

レイ飛地群連邦は、連続した単一国土ではなく世界各地の飛び地から成る。飛び地の起源は、過去の停戦協定、租借、移民、軍事拠点、国際管理地域などである。

| 地域 | 状態・役割 |
|---|---|
| ゼア大陸第1領 | 民主制。レイの首都候補地でもあるが、正式名称は未確定 |
| 西側大陸の第2領 | レイ第3領運河上の諸島と、その東側の三角州 |
| レイ第3領運河 | 西側大陸を二分する運河地域 |
| C国最北部 | 資源価値に乏しく、レイが管理 |
| B大陸半島群 | 資源価値に乏しく、レイが管理 |
| ゼア大陸北東部 | 資源価値に乏しく、レイが管理 |
| D・F連結諸島 | 資源価値に乏しく、レイが管理 |

レイ領は対立国の国境付近に置かれることが多く、緩衝地域として機能する。周辺国の文化・産業の影響が強いため、政治思想や軍制は地域ごとに異なる。連邦政府は外交と国防を主に統制し、内政は各飛び地へ大きく委ねる。

## エスティマ管轄領

- 太平洋西部の多数の島嶼と航路を管轄する。
- 主島に政府機関と人口の大部分が集中し、その他の島はほぼ無人。
- 首都島は唯一の絶対不可侵領域であり、無断接近は敵対行為と判断される。
- 周辺海域の通航は条件付きで認められる。

## エヌアポス管轄領

- 太平洋南東部の大島を中心とする。
- 環太平洋共同体の東側管轄を担当する。
- 港湾、工業地帯、資源輸送と航路の厳格な管理を重視する。

## 未確定事項

- 各領域の正式地名と境界線
- 各運河の国際法上の地位と通航制度
- レイ各領の番号と上記通称の正式な対応
- エヌアポスの周辺属島・領海範囲
