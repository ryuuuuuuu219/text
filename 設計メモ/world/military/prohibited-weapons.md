# 禁制兵器

## 禁制の原則

禁制の中心は威力の大小ではなく、戦闘から「敵の認識」「人間の判断」「危険の共有」「降伏の機会」「責任の所在」を取り除くかどうかにある。国連は古い騎士道的慣習を国際法へ組み込み、長距離自律誘導兵器や無差別兵器を規制している。

## 兵器別の扱い

| 区分 | 扱い | 主な条件・理由 |
|---|---|---|
| 機銃・機関砲・無誘導ロケット | 許容 | 目視戦闘を前提とする |
| VT信管 | 条件付き許容 | 射手が目標を確認する。救難機・民間機がいる空域では制限 |
| MACLOS手動誘導 | 許容 | 射手が目標と弾体を見て着弾まで操作する |
| レーザー誘導・レーダー指令誘導 | 条件付き許容 | 人間が目標を確認し、着弾まで関与する |
| セミアクティブ・レーダー誘導 | 論争中 | 発射者は照射を続けるが、目視原則との整合に賛否がある |
| 短距離ミサイル | 条件付き許容 | 目視、所属確認、視認距離内、追尾停止、発射者明示、誤射防止が必要 |
| 中距離ミサイル | 原則禁止または厳格制限 | 着弾時の確認、降伏判断、誤認時の停止が難しい |
| 長距離ミサイル | 禁制 | 視認、応答、降伏、停止、責任、戦闘員識別を損なう |
| 自律攻撃UAV | 禁忌級・禁制 | 通信なしで探索・選定・追跡・攻撃し、降伏や責任主体を必要としない |
| 徘徊型自爆無人機 | 禁制 | 空域を探索・待機し自律的攻撃へ移れる |
| 大量破壊兵器 | 否定・国際管理 | 無差別性、長期汚染、戦後被害、責任範囲の不明確さ |

## 長距離ミサイル

ゼアが高出力通信、慣性誘導、地磁気補正、予測演算、複数誘導方式、高度なECCM、限定的自律追尾を組み合わせて開発した。国連により禁制兵器へ指定されたが、技術が完全に放棄されたとは信じられていない。

## UAVの自律性

- 非武装観測・通信中継・救難UAVは概ね許容される。
- 遠隔操作式武装UAVは、人間による目標確認、発射判断、管制責任者の名乗りを条件に議論される。
- 半自律UAVは、人間が最終発射命令を出す限り容認する案がある。
- 自律攻撃UAVは、通信途絶後も目標選択と攻撃を続けるため禁忌級とされる。

## その他の禁止・制限

- 救難、降伏、休戦交渉、医療、国連共通通信への妨害は重大な禁忌。
- 大量チャフ散布は味方、救難、民間航空も妨害するため制限される。
- 核兵器は未製造。濃縮施設、反応設備、核物質輸送は国際管理下にある。
- 大規模化学兵器・生物兵器・都市無差別破壊兵器は否定されている。
- 反物質兵器は技術的に成立していない。
