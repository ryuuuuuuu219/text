# 現在の交戦国

## 確定している構図

**ゼア学園都市合衆国 対 他国家連合軍**

- ゼアは禁制兵器を実戦投入する敵国として設定されている。
- 国連加盟国は表向き長距離兵器の禁止を維持している。
- 各国はゼアが関連研究を完全に放棄したとは信じていない。
- エスティマ海域では、視認外からの航空機損失、所属不明の誘導弾残骸、異常な通信妨害、無人観測機、国籍不明試験機が確認されている。
- 自律攻撃UAVをゼア製と疑う現場反応案がある。

## 国家・組織別の状態

| 国家・組織 | 現時点で明記された状態 |
|---|---|
| ゼア | 交戦当事国。連合軍側から見た敵国。禁制兵器投入国 |
| 他国家連合軍 | ゼアと交戦。正式名称と構成国は未確定 |
| エスティマ | 主戦場・主人公空母の活動海域。国家としての参戦状態は未確定 |
| エヌアポス | 後方支援能力を持つが、支援対象と参戦状態は未確定 |
| レイ | 国連主導・仲介能力を持つが、中立か参戦かは未確定 |
| 国際連合 | 兵器規制を担う。軍事的な当事者性は未確定 |
| アレフィアほか六か国 | 参戦状態は未確定 |

## 未確定事項

- 開戦原因、宣戦経緯、戦争目的
- 他国家連合軍の正式名称・加盟国・指揮系統
- 主戦線と占領地域
- レイと国連の法的立場
- エスティマ、エヌアポス、その他六か国の参戦状態
- 禁制兵器投入が公知になる時期と、国連の対応
