機体識別・ダメージ表示UI 実装メモ

配置先
C:\▲\AirKnight\Assets\Scripts\MVP\空戦シーン\UI\一時的

目的
・航空機の敵味方を、機体直下の上向き三角形で常時識別できるようにする。
・弾着時に、受けたダメージ量を機体付近へ一時表示できるようにする。


1. 敵味方識別UI

表示仕様
・各航空機オブジェクトの子として識別マーカーを生成する。
・航空機のワールド座標をViewport座標へ変換し、Viewport基準で (0, -0.05) を加えた位置へマーカーを表示する。これにより解像度や機体までの距離にかかわらず、画面高の5%だけ機体の下へずれて見えるようにする。
・カメラから見た形が崩れないよう、三角形の正面は常にカメラ正面を向くビルボード表示とする。
・三角形の上方向は camera.transform.up に揃え、カメラの上下方向と三角形の上下方向を一致させる。三角形の頂点は常に画面上方向を向ける。
・味方は青系、敵は赤系で表示する。
・観戦対象は黄色、または外周の強調表示によって区別する。
・航空機が非表示または破棄された場合、マーカーも同時に非表示または破棄する。
・Viewport位置のClampは行わず、画面端ではマーカーが画面外へはみ出すことを許容する。画面外に専用の追従表示は出さない。

判定元
・AircraftFlightAI.affiliation を参照して敵味方の色を決定する。
・プレイヤー所属は BattleCommonScreenUI の playerAffiliation と同じ値を使用する。
・TargetLineUIManager.ObservationTarget と一致する機体を観戦対象として扱う。

想定スクリプト
・AircraftAffiliationMarker.cs
  航空機ごとのマーカー生成、位置、色、ビルボード回転を管理する。
・AircraftAffiliationMarkerManager.cs
  ActiveAircraftを監視し、生成済みマーカーと航空機の対応を管理する。


2. ダメージ表示UI

表示仕様
・弾着処理から明示的に呼び出されたときだけ生成する。
・ダメージ量を整数テキストとして弾着位置、または対象機体の位置へ表示する。
・表示直後は少し上へ移動し、時間経過で透明になって消える。
・連続弾着時に文字が完全に重ならないよう、生成位置へ小さなランダムずれを加える。
・味方へのダメージと敵へのダメージで文字色を変更できるようにする。
・ダメージが0以下の場合は表示しない。
・頻繁な生成に備え、最終実装ではGameObjectのプールを使用する。

想定スクリプト
・DamagePopupUI.cs
  1件のダメージ文字について、表示内容、移動、フェード、返却を管理する。
・DamagePopupManager.cs
  弾着側からの呼び出し窓口と、DamagePopupUIのプールを管理する。

想定呼び出し口
DamagePopupManager.ShowDamage(
    Vector3 worldPosition,
    float damage,
    AircraftAffiliation damagedAffiliation);

弾着側の処理順
1. 命中対象と弾着位置を確定する。
2. 実際に適用されたダメージ量を確定する。
3. ステータスへダメージを適用する。
4. DamagePopupManager.ShowDamageを呼び出す。


3. 共通方針

・表示はワールド空間に追従するが、文字と三角形はカメラ正面を向ける。
・Camera.mainが取得できない場合は表示更新を停止し、例外を発生させない。
・UI操作やPhysics判定を妨げないよう、識別マーカーとダメージ表示にはColliderを付けない。
・既存のAircraftObjectSelectorによる機体選択を妨げないレイヤーとする。
・大量表示時の負荷を抑えるため、毎フレームの全オブジェクト検索は行わない。
・具体的な寸法、オフセット、表示時間、色はSerializeFieldで調整可能にする。


4. 実装時に決める初期値

・三角形の機体下オフセットはViewport基準 (0, -0.05) を初期値とする
・三角形のワールド寸法
・観戦対象の強調方法
・ダメージ文字の上昇速度
・ダメージ文字の表示時間
・同時表示上限とプール数
・クリティカル、無効、撃墜時の追加表現を設けるか
