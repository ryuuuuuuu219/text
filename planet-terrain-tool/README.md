# TECTON — 惑星地形生成器

固定六角形グリッド上で、地殻情報そのものを移送しながらプレート領域を毎ステップ再構成するブラウザシミュレーターです。

## 起動

```powershell
cd C:\▲\planet-terrain-tool
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。外部パッケージのインストールは不要です。

## 操作

- 「開始」「＋1」で同時更新を実行
- 横16〜72、縦10〜44の範囲でグリッド数を指定して惑星を再生成
- 火山圧力 `X`、影響半径 `R`、地形崩壊速度・範囲を実行中に調整
- 継承拡散率に応じ、主方向または左右隣の60度方向へ確率的に継承（地殻を複製しないため質量増加なし）
- セルをクリックすると地殻厚、地底高度、密度、年代、温度、運動と継承方向を表示
- セルをダブルクリック、または Shift+クリックすると火山源を追加・除去
- 表示タブで標高、再構成プレート、年代、温度、密度を切替
- 「保存」「読込」で全状態を JSON として受け渡し

## モデル上の扱い

- 現在・次状態を分離したダブルバッファ更新
- 前速度、距離減衰する火山斥力、近傍境界補正を合成し、最近傍の六方向へ地殻を継承
- 複数流入は密度と厚みに応じて沈み込み、または双方を圧縮
- 火山域・発散域の空隙に薄く高温な新生地殻を生成
- 運動方向を60度刻みの6方向へ量子化し、同じ方向ビンの連結成分をプレートとして毎ステップ再識別
- 衝突で生じた堆積厚を追跡し、地形崩壊速度・範囲に従って低い地殻へ同時拡散
- 地表高度は地底高度、地殻厚、密度による簡易アイソスタシー式で算出

世界地図は東西方向のみ連続し、南北端は接続しません。南北端から外へ向かう地殻は端のセルに留まります。純粋な六角形だけで球面を覆えないため、球体表示や極域の五角形セルは将来拡張の対象です。
